Show what each session is doing, right in its row

Today a row in the sessions list shows a title and a branch. You can see that a session is busy, done, or waiting for you. You cannot see what it is busy with, or what it asks you, without opening it.

The plan: add one short line under the branch. It says what the session just did, or the question it is waiting on. Nothing else in the row changes.

How the line behaves

  • Why a third line, not the second. The second line (agent icon, branch, memory) stays exactly as it is: it already says which agent and which branch, and many tests find a row by it. The new line goes under it.
  • “Asks: …” and “Wants to run: …” show only while the row is amber (the session is waiting on you). Once you answer, or press Esc in the terminal, the row stops being amber and the line goes back to what it did.
  • What it did is the session’s own last tool. A helper it started (a subagent) does not show here.
  • “Last: …” (Option 1) shows after a turn ends and is replaced as soon as the next turn does something.
  • A fresh start empties the line: /clear, a resume or a restart in the same tab start with no line until the new session does something.
  • Only while Koloft runs. The line is not saved: after Koloft restarts, a row has no line until its session does something again. A row that is not running (grey bar) never has one.
  • Rows that keep two lines: the butler’s row at the top, and a row still waiting to start.
  • Same for a Claude Code plan: its “Approve this plan?” question shows as “Asks: Approve this plan?”.

How it is built

  • No new hook and nothing extra per tool call: Koloft already receives every one of these events. What is new is reading a few more fields out of them (the command of a running Codex command, the plan item at the end of a Codex Plan turn) and passing two short values per row to the window.
  • The row only redraws when its own line changes; other rows stay as they are.
  • Tests: one table of tool names to words for each agent, the row with and without the line, and one end-to-end flow per agent on this Mac, plus Claude Code and Codex on another machine.
