#8 — the plan Claude Code wrote, shown read-only in the Workbench

Claude Code (version 2.1.286–2.1.288) writes its plan to ~/.claude/plans/<slug>.md with the ordinary Write tool, and Koloft already lists every Markdown file a session wrote on the preview card. So the plan row already exists — it just hides under "Docs" with a made-up name. This design only names it: a Plan group above Docs, same row, same click. Nothing opens by itself, and there is no approve or reject button anywhere — the roadmap rejects answering the TUI from Koloft, so the plan is approved where its prompt appears: in the terminal.
