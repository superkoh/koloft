Accounts

Every session in Koloft runs on an account from its agent’s section below, never on the login already on this Mac. Each new session picks its agent’s least-used sign-in, and an API key only when every sign-in is at its limit.

Skip permission prompts Adds --dangerously-skip-permissions to Claude and Antigravity when Koloft injects an account, starts Muse with :unrestricted, and starts new Codex sessions with -a never -s danger-full-access — never overrides permission flags you pass yourself.
Only this Mac and the hosts below Commands a Claude Code or Codex session on this Mac runs reach this Mac (the Workbench browser, a dev server) and the hosts below, and nothing else on the internet. Those sessions then run in their own sandbox instead of skipping permission prompts, and ask before anything outside it. Applies to sessions started after a change. Muse, Antigravity and sessions on another machine are not limited.
Allowed hosts Separate them with commas. *.example.com takes every name under it.
Account usage Reads again, right now, how much every enabled account of every agent has used.
