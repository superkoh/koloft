左边的竖条："working" 橙色呼吸、"waiting" 绿色、"approval" 琥珀色一跳一跳；限额是不动的、半透明的琥珀色，意思是"在等钟，不是在等你"。

"working"：正在干活 "waiting"：这一轮做完了，轮到你 "approval"：卡在一个要你点头的框上（会一跳一跳） new "limited"：撞到用量限额，等重置

行上的第二行字（在 worktree 名字后面，琥珀色）

什么时候第二行写什么红点
撞到限额，Claude Code 会自己接着干（或 Codex 由 Koloft 接着干）main · limited until 14:05没有
Mac 睡过了重置，Claude Code 没自己接上main · limited · press Enter有
Claude Code 不会自己接上（自动继续关了 / 重置在 24 小时之外 / 连撞上限 / 只是 Fable 额度用完）main · limited · will not go on有
撞到限额但拿不到时间（Codex 读不到账号额度）main · limited没有

时间用用量胶囊里同一个格式：当天就 14:05，不是当天就 10-20 14:05。鼠标停在行上，提示框说明是谁会接着干。

Codex：到点了，会话闲着、你也没往里打过字，Koloft 替你敲了 "continue" + Enter。

撞到限额的那一刻不发通知（主人定的：接上的时候才通知）。窗口在前台时也不发，行上的样子已经说明了。绑了 Discord 的工作区：撞限额时不发 "finished" 卡片，会话卡片改画 "⏳ limited until 14:05"，上面四句话同样发到会话的 thread 里。
