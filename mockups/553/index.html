#553 正在跑的 Codex 标签页，仓库后来选了账号，还是连不上网

现在是这样：Codex 标签页在启动那一刻决定它的沙盒能不能上网。仓库启动时已经选了 git 账号，就能上网；后来才选的，这个标签页的 git push 一直失败，直到重启它，面板上也不说。

只有两种人会碰到：本机 Codex 且 Settings 里关了 Workbench 浏览器（默认是开的，开着时本机 Codex 标签页本来就能上网）；以及所有远程 Codex 标签页（远程不走浏览器那条路）。其他六种标签页选完账号立刻就能用，见最下面的表。

选项一（推荐）：所有 Codex 标签页的沙盒都开网，像 Muse 一样 —— 界面不变

不用画图：面板和今天一模一样，只是正在跑的 Codex 标签页选完账号后下一次 git push 就能成功。代价写在问题里。

选项二：在选账号的面板里列出要重启的标签页，带 "Restart"

鼠标停在工作区的 git 标记上会弹出这个面板（"Account" 那一段是 #552 加的）。虚线框是新加的：一句提示，加上每个受影响标签页一行 "Restart"。按钮、提示、图标都用面板里已有的 .tbu-act、.fx-note warn、IconReload。

  • 哪些标签页算"受影响"：这个仓库里（含它的 worktree）正在跑、启动时没开网的 Codex 标签页。启动时已经开了网的（浏览器开着、"skip permission prompts" 开着）不列。
  • 点 "Restart"：和现在 ⌘R 重启一样，接着同一个对话，正在跑的那一回合会被打断。右边小字 "idle"/"working" 让人知道会不会打断。
  • 重启完、或标签页关掉，那一行就消失；面板关了再打开，没重启的还在。
  • 远程工作区的面板一样：列这台机器上的 Codex 标签页。

选项三：不加界面，那个标签页下一次空下来时 Koloft 自动重启它

不用画图：面板不变，选完账号后，受影响的 Codex 标签页在它这一回合做完、等人说话时自己重启一次（接着同一个对话）。
