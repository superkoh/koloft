⌘P, one box for everything

Type a line. It starts, finds or searches.

The one box you keep coming back to: new work, any old session, anything you said.

One sentence → a working session

Press ⌘P, type “add a forgot-password link to the login page” and hit ⏎. Assist picks the folder, opens a worktree when the folder is a git repo, names the session, and the agent you picked starts on your words. Type @ and a folder's name to pick the folder yourself. The ▾ beside the button, or ⌘⏎, picks another agent; ⇧⏎ starts a new line.

  • ✓ Claude Code
  • ✓ Codex
  • ✓ Remote

Needs Assist on (Settings ▸ Assist); with it off, ⏎ opens the folder picker and keeps your words, unless you named a folder with @. In a remote folder the session opens on that machine.

Worktrees

Parallel work that does not collide.

Every session in a git folder can have a worktree of its own: a separate copy of the code on its own branch.

Start from an issue or pull request

⇧⌘N lists a GitHub repo’s open issues and pull requests. Pick one and the session starts in its own worktree, already told to read that issue.

  • ✓ Claude Code
  • ✓ Codex
  • ✓ Remote

Needs gh signed in. In a remote folder the worktree is made on that machine.

Read more

A port of its own, files copied in

Each worktree session gets KOLOFT_PORT_OFFSET (1–99, the same number for the same worktree name), so two dev servers do not fight over port 3000. Files listed in .worktreeinclude, such as .env, are copied into each new worktree.

  • ✓ Claude Code
  • ✓ Codex
  • ◐ Remote

In remote folders the port offset works; copying files does not yet.

Your butler hands out the work

Hand it the work. It reports back.

Your butler, Alfred until you rename it, is Koloft’s own AI: one Claude, Codex, Muse or Antigravity session on an account you added, first in the sessions list.

Starts sessions, hears them finish

Say “have tidewatch fix the login bug”: your butler starts the session, answers its questions the way you tell it, and tells you when it is done. A job outside your projects, or a ⌘P request Koloft cannot do by itself (with Assist on), goes to a helper of its own, which hangs under its row, does the job and reports back.

  • ✓ Claude Code
  • ✓ Codex
  • ✓ Remote

The butler runs on your Mac; it can start, message, read and resume a session in a remote folder too.
