Your Claude Code and Codex sessions, one folder at a time.

Koloft is a Mac app. Pick a folder, and it lists every Claude Code and Codex session that folder has. Start a new one or pick up an old one — and beside each session sits a Workbench: the files the agent changed, a file browser, web pages and a shell.

Install Source on GitHub

macOS on Apple Silicon · Free and open source (GPL-3.0)

The real tool, untouched

The middle of the window is claude or codex itself, in a real terminal. Koloft adds what sits around it and never paints over it.

Nothing to import

The list is read straight from what Claude Code and Codex already save on disk, so sessions you started from a plain terminal show up too.

Nothing reported

No sign-up, no analytics, no telemetry. Your sessions talk to Anthropic and OpenAI the same way they always do.

What you get

Folders and their sessions

Pin folders as workspaces. Each session under one shows a title, when it last ran and, for sessions Koloft started, a status dot (working, waiting for you, done). Click an old one to resume it.

A Workbench per session

The files this session changed with their diffs, a tree of the folder, rendered Markdown, images and PDF, an editor, web pages and a shell — all kept with that session.

Worktree sessions

Start a session in its own git worktree with one shortcut, so two agents can work on the same project without stepping on each other.

A browser the agent can drive

Pages the agent opens land in the Workbench, not in another app. Playwright tools in a Claude session drive these tabs with nothing to set up — and one switch turns that off.

A note per folder

A plain-text note that belongs to the folder, not the session, for the things that should outlive today's work.

Scheduled sessions

Start a Claude or Codex session on a timer with a first message. Koloft hands that message to the tool once; everything after it is yours.

Several accounts, one pool

Add more than one Claude or Codex account. Every new session starts on the one with the most room left. The top bar shows what your Claude accounts have left; Codex accounts show theirs in Settings.

Know when it is your turn

A system notification, while Koloft is in the background, when a session finishes or waits for your approval, and, in Claude sessions, a built-in status line with model, cost, context and git branch.

Remote folders alpha

Run Claude on another machine you can reach over ssh. It keeps running if the link drops, and the list reads the same as a local folder.

Install

Paste this into Terminal. It downloads the latest release and puts Koloft in Applications. 

curl -fsSL https://raw.githubusercontent.com/superkoh/koloft-releases/main/install.sh | bash
  • You need: a Mac with Apple Silicon (M1 or later), and Claude Code or the Codex CLI installed. There is no Intel, Windows or Linux build.
  • Why a Terminal command? Koloft is not signed by Apple — that needs a paid Apple Developer ID this project does not have. A file downloaded in a browser gets flagged, and macOS then refuses to open it. A file fetched with curl is not flagged, so the app opens with a normal double-click.
  • Rather download it yourself? Get the .dmg from Releases, drag Koloft to Applications, then clear the flag once: 
    xattr -dr com.apple.quarantine /Applications/Koloft.app
  • Updates: Koloft checks for new versions itself, and Koloft ▸ Check for Updates… does it on demand.

Questions

Does Koloft replace Claude Code or Codex?

No. It runs the real claude and codex command-line tools you already have, and shows their own screen, untouched. Koloft adds the list, the Workbench and the note around it.

Does it cost anything?

Koloft is free. Claude Code and Codex use your own Anthropic or OpenAI account, as they do without Koloft.

What does Koloft connect to?

Only what it needs: GitHub to check for updates, Anthropic to read how much allowance your accounts have left when you add several, DuckDuckGo for what you type in the browser's address bar that is not a link, and a few hosts for optional features like remote folders and browser extensions. The full list is in the README.

Can I help?

Bug reports and ideas are very welcome as issues. Koloft does not take pull requests yet; the code is there to read, build and run.

The roadmap lists what is planned and what is deliberately left out.
