Not a replacement. Koloft runs the claude and codex you already have and never covers their screen. A terminal can't tell you which of nine tabs is waiting, can't spread your sessions over two accounts, and can't hand out work for you.

01 · ⌘P, one box for everything

Start it, find it, or search it — from one line.

You never have to think about where a session goes or where an old one went. Type, and the same box starts new work, jumps to any session, or searches every conversation you have had.

Assist picks the placeThe folder, a worktree of its own when the folder is a git repo, and a short title. Not sure? It asks you which folder.
Either tool⏎ starts your default tool; ⇧⏎ the other one when you have both. Name a GitHub issue and it starts in that issue's worktree, told to read it first (with gh signed in).
More than startingask tidewatch … goes to that folder's Assist; a brand-new idea gets a new project folder (you pick where projects live, once).

notePicking the place needs Koloft Assist on (Settings ▸ Assist); with it off, ⏎ opens the folder picker with your words kept. Codex runs in local folders only, and in remote folders search matches session titles, not what was said.

02 · Every session, one list

The ones that need you are marked.

Ten sessions in five folders, and you still know which one is waiting. A red dot when a turn ends; ⌘J jumps to the one that has waited longest.

Read from the tools' own filesNothing to import. Close Koloft and every session is still there.
Lights that mean somethingBreathing orange: working. Green with a red dot: done, not seen yet. Amber: waiting for your OK.
Sessions an agent startsThey hang under the session that started it, as a tree.

03 · The real terminal, and a Workbench

The agent's own screen stays as it is.

The middle of the window is Claude Code's or Codex's own terminal. Beside it hangs a Workbench for that one session: every change as a live diff, the files, web pages, a shell.

The Workbench
Comment on a change✎ on any hunk; your note lands in the session's input box.
Your browser, for the agentA web tab is a real browser, logins and all. The agent can open it and drive it with the playwright-cli that comes with Koloft (on your Mac; not yet in remote folders).
Pull requests and checksCommit, push, open the PR; a failing check's log goes back to the session in one click.
04 · Assist hands out the work

Ask once. Assist starts the session and tells you when it's done.

Koloft's own AI lives under your sessions list. It starts sessions, answers their questions, and hears their reply when a turn ends. It never edits a file itself.

From your phone, tooBind Assist to your own Discord bot. One thread per session, Yes / No buttons, files out.
Your bot, your serverNo server of ours in between. Assist does the clicking and typing; you sign in, pass the human checks, and press the few buttons Discord only lets a person press.
Runs on your accountAssist is an ordinary Claude or Codex session on an account you added, so it uses your plan like any session.

noteAssist runs on your Mac and starts sessions there; it can message a session in a remote folder once that session's turn ends. Questions with several parts, pick-many answers or free text get no Discord buttons: tell Assist what to pick.

Several accounts, one pool

No more “limit reached”.

Add your Claude and Codex accounts. Each new session starts on the one with the most room left (for Claude, counting the sessions already on it); a resumed session stays on its own until it is 95% used. Git accounts too, one per repository: GitHub, GitLab, Bitbucket, Azure DevOps, Gitea or any server.

noteshown here: three Claude accounts. Codex accounts sit in the same list with their own bars.

Several accounts, one pool

Sessions on a timer

Every hour, day or week; in a git folder, in a worktree of its own. Tell it to close when done and it tidies up, unless work is left uncommitted or unmerged.

Remote folders alpha

A folder on a machine you reach over SSH. Claude runs there in tmux, so a dropped line doesn't stop it. Claude only for now, and the agent can't drive web tabs there yet.

Everything comes with it

git, gh and playwright-cli ship inside. On a fresh Mac, one click installs Claude Code or Codex.

Start from an issue

⇧⌘N lists a GitHub repo's open issues and pull requests; pick one and it starts in its own worktree.

Our promise

What it will never do

  • ask you to sign up

    No Koloft account. It runs on your own Claude or Codex login.

  • track you

    No analytics. The few places it talks to are all listed.

  • copy your chats

    It reads the tools' own records and never keeps a copy of your chats.

  • cover the agent

    Nothing is drawn over the agent's terminal.

Give your agents a home.
