Install, update, what it talks to

Koloft is a free Mac app. One line in Terminal installs it. This page says why it is a Terminal line, what you need, how Koloft stays up to date, and every place on the internet it talks to.

Install

Open Terminal, paste this line and press Return. It finds the newest release and puts Koloft in your Applications folder.

curl -fsSL https://raw.githubusercontent.com/superkoh/koloft-releases/main/install.sh | bash

Why a Terminal line?

Koloft is not signed by Apple. Signing needs a paid Apple Developer ID, and this project does not have one. When a browser downloads an app like that, macOS puts a quarantine mark on it. Gatekeeper (the part of macOS that checks apps before they open) then blocks it and calls it "damaged" or from an "unidentified developer".

curl (the download tool inside Terminal) never adds that mark. So the app it fetches opens with a normal double-click, with no prompt.

Rather download it yourself?

Get the .dmg (the disk image a Mac app comes in) from Releases. Drag Koloft to Applications. Then clear the mark once:

xattr -dr com.apple.quarantine /Applications/Koloft.app

What you need

  • a Mac with Apple Silicon (M1 or later)
  • Claude Code, or the Codex CLI (command-line tool), already installed. Each Koloft version names the oldest Claude Code and Codex it works with, and updates an older one for you (see Updates below).
  • if you like: gh, GitHub's own command-line tool, signed in, for a folder's open issue and pull request counts, a branch's checks, and a Discord conductor's koloft gh
  • if you like: a Discord account, for the butler on Discord

Updates

Koloft ▸ Check for Updates… opens a window. Download & Restart fetches the new version, quits Koloft, swaps it in and opens it again. A banner in the sidebar tells you when a newer one is out. What changed in each version is in the changelog.

Koloft also keeps Claude Code and Codex new enough. If yours is older than this version works with, Koloft runs claude update or codex update for you. For Claude, this runs in the tab each time a session starts. For Codex, it runs once each time Koloft opens, with a small message. If that does not bring it up to date, Koloft asks you to run the update yourself.

What it talks to

Koloft never counts, tracks or reports what you do. Nothing about you is sent anywhere, unless you turn on the Discord butler: then what A butler on Discord lists goes to your own bot. These are the only hosts it ever reaches on its own:

host why
api.anthropic.com each account's room left, as a session starts and every 5 minutes. Through claude, the small jobs of Koloft Assist when it runs on Claude
api.github.com,
github.com		 a newer Koloft and its .dmg; through gh, issue and pull request counts, a branch's checks, and what a Discord conductor asks with koloft gh
your folder's
git remote		 often github.com; every 5 minutes, to see if your branch is behind
claude.ai,
nodejs.org,
unofficial-builds.nodejs.org 		only to put claude and Node on a remote folder's machine (the third on an old Linux)
chromewebstore.google.com,
clients2.google.com,
update.googleapis.com 		Chrome extensions only: the store, the download, a check once per launch
discord.com,
gateway.discord.gg		 only once you paste a bot token; see A butler on Discord
duckduckgo.com words, not a web address, typed into the in-app browser, as a search

A few more details:

  • an API key, or an account on your own endpoint, gets the same tiny message there, only to check it still works
  • the status line under each session asks gh about the branch's pull request
  • with Koloft Assist on Codex, its small jobs go through codex to OpenAI, the same way a Codex session does
  • the git check can be turned off in Settings ▸ Appearance ▸ Auto-fetch git remotes
  • when Koloft runs claude update or codex update for you, the tool fetches its own update, from the place it was installed from
  • for a remote folder, bash, tmux and rsync come from that machine's own package manager, which may ask for its sudo password (the admin password)
  • the store page loads only when you click Open Chrome Web Store in Settings ▸ Extensions
  • with a bot token pasted in Settings ▸ Discord, your messages, and your sessions' replies, questions and approvals, go to your own bot; files you send are fetched from the address Discord gives for them (its own file host)

A remote folder also reaches the machine you named, over ssh (a safe way to log in to another computer) and rsync (a tool that copies files).

Claude Code talks to Anthropic and Codex talks to OpenAI by themselves, when you log in and every time you send a message. That traffic is theirs, not Koloft's, and this list does not cover it. Koloft also asks Codex how much of each account's limit is left. Codex makes that call itself, through codex app-server.

Questions

Does Koloft replace Claude Code or Codex?
No. It runs the real claude and codex tools you already have, and shows their own screen, untouched. Koloft adds the list, the Workbench and the note around it.
Does it cost anything?
Koloft is free. Claude Code and Codex use your own Anthropic or OpenAI account, just as they do without Koloft.
Is there a version for Intel Macs, Windows or Linux?
No. Koloft is built for Macs with Apple Silicon only, and the install line stops on any other computer.
I started a session in a plain Terminal. Can Koloft open it?
Yes. Right-click the folder in Koloft and pick Restore session…. See Folders and their sessions.

Help and plans

Bug reports and ideas are welcome as issues. Koloft does not take pull requests (code changes sent in by others) yet. The code is there to read, build and run.

The roadmap lists what is planned, what is left out on purpose, and how much to trust the order.

Found a security problem? Please do not open a public issue. Read SECURITY.md first.
