Install, update, what it talks to

Koloft is a free Mac app. One line in Terminal installs it. This page says why it is a Terminal line, what you need, how Koloft stays up to date, and every place on the internet it talks to.

Install

Open Terminal, paste this line and press Return. It finds the newest release and puts Koloft in your Applications folder.

curl -fsSL https://raw.githubusercontent.com/superkoh/koloft-releases/main/install.sh | bash

Why a Terminal line?

Koloft is not signed by Apple. Signing needs a paid Apple Developer ID, and this project does not have one. When a browser downloads an app like that, macOS puts a quarantine mark on it. Gatekeeper (the part of macOS that checks apps before they open) then blocks it and calls it "damaged" or from an "unidentified developer".

curl (the download tool inside Terminal) never adds that mark. So the app it fetches opens with a normal double-click, with no prompt.

Rather download it yourself?

Get the .dmg (the disk image a Mac app comes in) from Releases. Drag Koloft to Applications. Then clear the mark once:

xattr -dr com.apple.quarantine /Applications/Koloft.app

What you need

  • a Mac with Apple Silicon (M1 or later)
  • Claude Code, or the Codex CLI (command-line tool), already installed

Updates

Koloft ▸ Check for Updates… opens a window. Download & Restart fetches the new version, quits Koloft, swaps it in and opens it again. A banner in the sidebar tells you when a newer one is out.

What it talks to

Koloft never counts, tracks or reports what you do. Nothing about you is sent anywhere. These are the only hosts it ever reaches on its own:

host why
api.anthropic.com sends each account a tiny message and reads how much room is left from the reply. An account on your own endpoint is asked there instead
api.github.com, github.com checks for a newer Koloft and downloads its .dmg
your folder's git remote often github.com; asked every 5 minutes, to see if your branch is behind. Turn it off in Settings ▸ Appearance ▸ Auto-fetch git remotes
claude.ai, nodejs.org only for a remote folder, and only to install what that machine is missing: claude from the first, Node from the second; tmux and rsync come from that machine's own package manager, which may ask for its sudo password (the admin password)
clients2.google.com,
update.googleapis.com		 only if you installed a Chrome extension in the in-app browser: the first gives the extension, the second checks once per launch for a newer one
duckduckgo.com when you type words, not a URL (a web address), into the in-app browser, they go here as a search

A remote folder also reaches the machine you named, over ssh (a safe way to log in to another computer) and rsync (a tool that copies files).

Claude Code talks to Anthropic and Codex talks to OpenAI by themselves, when you log in and every time you send a message. That traffic is theirs, not Koloft's, and this list does not cover it. Koloft also asks Codex how much of each account's limit is left. Codex makes that call itself, through codex app-server.

Questions

Does Koloft replace Claude Code or Codex?
No. It runs the real claude and codex tools you already have, and shows their own screen, untouched. Koloft adds the list, the Workbench and the note around it.
Does it cost anything?
Koloft is free. Claude Code and Codex use your own Anthropic or OpenAI account, just as they do without Koloft.
Is there a version for Intel Macs, Windows or Linux?
No. Koloft is built for Macs with Apple Silicon only, and the install line stops on any other computer.
I started a session in a plain Terminal. Can Koloft open it?
Yes. Right-click the folder in Koloft and pick Restore session…. See Folders and their sessions.

Help and plans

Bug reports and ideas are welcome as issues. Koloft does not take pull requests (code changes sent in by others) yet. The code is there to read, build and run.

The roadmap lists what is planned, what is left out on purpose, and how much to trust the order.

Found a security problem? Please do not open a public issue. Read SECURITY.md first.
