Install, update, what it talks to

Koloft is a free Mac app, signed and notarized by Apple (Apple has checked it). Download it and drag it to Applications, or let one line in Terminal do that. This page says what you need, how Koloft stays up to date, and every place on the internet it talks to.

Install

Get the .dmg (the disk image a Mac app comes in) from Releases. Open it and drag Koloft to Applications. Koloft is signed with an Apple Developer ID and notarized, so it opens with a normal double-click.

Or one line in Terminal

Open Terminal, paste this line and press Return. It finds the newest release and puts Koloft in your Applications folder, in place of an older copy.

curl -fsSL https://raw.githubusercontent.com/superkoh/koloft/main/install.sh | bash

What you need

  • a Mac with Apple Silicon (M1 or later)
  • one of the agents: Claude Code, the Codex CLI (command-line tool), Meta's Muse Code or Google's Antigravity CLI. The first screen of the welcome says which ones are on this Mac. For one that is not, press its Install button and a terminal tab runs the tool's official installer. Signing in on the welcome also installs the tool first when it is missing. Settings ▸ Welcome ▸ Show welcome again brings the welcome back. Later, Sign in to Codex, Sign in to Muse or Antigravity's Sign in with Google in Settings ▸ Accounts does the same for a tool the Mac still lacks. Each Koloft version says how old each agent may be, and updates an older one for you (see Updates below).
  • a Claude, Codex, Muse or Antigravity login to add to Koloft: every session runs on one (see accounts)
  • git and gh (GitHub's own command-line tool) come with Koloft. If your Mac already has its own, Koloft uses yours. Sign in to gh yourself (gh auth login), or add a git account in Koloft and pick it for the folder. That gives you a folder's open issue and pull request counts, a branch's checks, and koloft gh for your sessions and your butler
  • if you like: a Discord account, for the butler on Discord

Updates

Koloft ▸ Check for Updates… opens a window. Download & Restart fetches the new version, quits Koloft, swaps it in and opens it again. A banner in the sidebar tells you when a newer one is out. What changed in each version is in the changelog.

Koloft also keeps the agents new enough. If yours is older than this version works with, Koloft runs the tool's own update for you, such as claude update or codex update. For Claude, this runs in the tab each time a session starts. For Codex, Muse Code and Antigravity CLI, it runs once each time Koloft opens, with a small message. If that does not bring it up to date, Koloft asks you to run the update yourself.

A few more details:

  • an API key, or an account on your own endpoint, gets the same tiny message there, only to check it still works
  • the status line under each session asks gh about the branch's pull request
  • with Assist on Codex, Muse or Antigravity, its small jobs go through that tool to OpenAI, Meta or Google, the same way a session does
  • a Muse or Antigravity account's allowance is read by running muse or agy itself; that call is the tool's own, like Codex's
  • the git check can be turned off in Settings ▸ Appearance ▸ Auto-fetch git remotes
  • when Koloft runs claude update or codex update for you, the tool fetches its own update, from the place it was installed from
  • for a remote folder, bash, tmux, rsync and python3 (for Muse) come from that machine's own package manager, which may ask for its sudo password (the admin password)
  • the store page loads only when you click Open Chrome Web Store in Settings ▸ Extensions
  • with a bot set up in Settings ▸ Discord, your messages and your butler's replies, its questions and its helpers' questions, and the 🔑 cards for a session's password or code go to your own bot. Files you send are fetched from Discord's own file host

A remote folder also reaches the machine you named, over ssh (a safe way to log in to another computer) and rsync (a tool that copies files).

Claude Code talks to Anthropic, Codex to OpenAI, Muse Code to Meta and Antigravity to Google by themselves, when you log in and every time you send a message. That traffic is theirs, not Koloft's, and this list does not cover it. Koloft also asks Codex how much of each account's limit is left. Codex makes that call itself, through codex app-server.

Questions

Does Koloft replace Claude Code, Codex, Muse Code or Antigravity?
No. It runs the real claude, codex, muse and agy tools you already have, and shows their own screen, untouched. Koloft adds the list, the Workbench and the note around it.
Does it cost anything?
Koloft is free. The agents use your own Anthropic, OpenAI, Meta or Google account, just as they do without Koloft.
Is there a version for Intel Macs, Windows or Linux?
No. Koloft is built for Macs with Apple Silicon only, and the install line stops on any other computer.
I started a session in a plain Terminal. Can Koloft open it?
Yes. Right-click the folder in Koloft and pick Restore session…. See Folders and their sessions.

Help and plans

Bug reports and ideas are welcome as issues. Koloft does not take pull requests (code changes sent in by others) yet. The code is there to read, build and run.

The roadmap lists what is planned, what is left out on purpose, and how much to trust the order.

Found a security problem? Please do not open a public issue. Read SECURITY.md first.
